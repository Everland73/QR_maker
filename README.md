# QR 스튜디오

링크 여러 개를 이미지가 중앙에 들어간 QR 코드로 만들고, 선택한 폴더에 PNG로 저장하는 브라우저 앱입니다. 입력한 링크와 이미지는 서버로 전송되지 않습니다.

## 실행

```bash
npm install
npm run dev
```

폴더에 직접 저장하는 기능은 File System Access API를 사용하므로 Chrome 또는 Edge에서 실행해 주세요. 생성 버튼을 누르면 저장할 폴더를 선택합니다. 링크는 한 번에 최대 10개까지 입력할 수 있으며, 중앙 이미지는 선택 사항입니다.

프로덕션 빌드는 `npm run build`로 만들 수 있습니다.
